# Waveshare AMOLED 1.43C — Book and Firmware Flash Guide

This guide explains how to load books and update the firmware on the
**Waveshare ESP32-S3-Touch-AMOLED-1.43C** device, which has no SD card slot.
Books are loaded directly into internal flash storage via LittleFS.

---

## Prerequisites

- [PlatformIO](https://platformio.org/) installed (CLI or VS Code extension)
- USB-C cable connected to the device
- PowerShell (Windows) — minimum version 5.1
- Repository cloned on the `release/amoled-143` branch

---

## Flash Memory Layout

| Partition  | Type      | Offset     | Size       | Contents              |
|------------|-----------|------------|------------|-----------------------|
| `nvs`      | NVS       | `0x9000`   | 20 KB      | Saved settings        |
| `app0`     | Factory   | `0x10000`  | 3 MB       | Firmware              |
| `spiffs`   | LittleFS  | `0x310000` | ~4.875 MB  | Books and data files  |
| `coredump` | Coredump  | `0x7F0000` | 64 KB      | Crash diagnostics     |

## Adding Books

### Supported Format

Books must be in **`.rsvp`** format (plain text for RSVP reading).

> ⚠️ **Important**: Filenames **must not contain spaces**.
> The flash script automatically removes spaces from filenames before flashing.

### 1. Copy files to the correct folder

Place `.rsvp` files in:

```
data/books/books/
```

Example:

```
data/
└── books/
    └── books/
        ├── DungeonCrawlerCarl.rsvp
        ├── My_Book.rsvp
        └── ...
```

> Files in `data/books/articles/` appear under the **Articles** section instead.

## Flashing Firmware and Books

### Automatic script (recommended)

From the repository root, run:

```powershell
.\tools\flash_143c.ps1
```

The script runs these steps automatically in order:

1. **Stale file cleanup** — removes any files generated by previous builds
2. **Space rename** — removes spaces from filenames
3. **Space check** — verifies that books fit in the LittleFS partition (~4.4 MB usable)
4. **Flash filesystem** (`uploadfs`) — writes books to LittleFS at `0x310000`
5. **Flash firmware** (`upload`) — installs firmware and updated partition table

#### Expected output

```
==> Checking for spaces in filenames...
   No spaces found.

==> Checking available space...
   Partition : 5000 KB  (usable ~4500 KB after LittleFS overhead)
   Data size : 856 KB  (19% of usable space)
   Space OK.

==> Flashing filesystem (books)...
   [...]

==> Flashing firmware...
   [...]

Done! Books and firmware flashed successfully.
```

---

### Manual flash (alternative)

To run commands separately:

```powershell
# Filesystem only (books)
pio run -e waveshare_esp32s3_touch_amoled_143c -t uploadfs

# Firmware only
pio run -e waveshare_esp32s3_touch_amoled_143c -t upload
```

> ⚠️ Always run `uploadfs` **before** `upload`, otherwise the updated partition
> table may not match the image already loaded.

## Serial Monitor (debug)

To verify correct operation after flashing:

```powershell
pio device monitor -e waveshare_esp32s3_touch_amoled_143c
```

### Expected boot log

```
[sd-check] internal flash mounted: used=XXX total=5111808 free=XXX bytes
[book-scan] found: /books/books/DungeonCrawlerCarl.rsvp size=876856
[book-scan] dir /books/books: 1 entries
[storage] Directory inventory: 3 files, 1 books, 0 cache probes in XX ms
```

### Common errors

| Message                            | Cause                                         | Fix                                                   |
|------------------------------------|-----------------------------------------------|-------------------------------------------------------|
| `internal flash mount failed`      | LittleFS partition not found                  | Re-run `flash_143c.ps1` with the current version      |
| `Not enough space for sidecar`     | File too large to index                       | LittleFS has ~4.4 MB usable; remove excess books      |
| `data sidecar flush failed`        | Storage full during indexing                  | Check free space via serial monitor                   |
| `Failed to load selected book`     | Indexing failed                               | See serial log for details                            |

## Disabled Features on This Device

The 143C is configured for **offline use**. The following features are unavailable
(flag `RSVP_NO_WIFI=1`):

- OTA (Over-The-Air) firmware updates
- RSS feeds
- Companion app sync
- Wi-Fi settings

---

## Practical Limits

| What                    | Limit                                                                                                                       |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| Total book storage      | ~4.4 MB usable (LittleFS overhead ~10%)                                                                                     |
| Single book size        | No fixed limit; depends on free space. For books >1.5 MB verify enough room for sidecar files (~2× the book's size)        |
| Filename                | No spaces (automatically removed)                                                                                           |
| Supported format        | `.rsvp`                                                                                                                     |

---

## Sidecar Structure (auto-generated)

When you open a book for the first time, the device creates auxiliary index files in LittleFS:

```
/books/books/
├── MyBook.rsvp          ← source book (loaded via uploadfs)
├── MyBook.rsvp.rdat     ← word data  (generated on first open)
└── MyBook.rsvp.ridx     ← word index (generated on first open)
```

These files are created automatically and do not need to be uploaded manually.
